# 작업 폴더 편집 및 탐색 정리 검증

2026-09-15 최종 구현 기준.

## 반영

- `폴더에서 보기` → 커밋 그래프 위치에 작업 폴더 탭. 그래프 탭으로 복귀 가능하며 닫기 버튼·Esc를 지원한다.
- 왼쪽 편집기에서 실제 파일을 수정하고 `파일 저장` 또는 Cmd/Ctrl+S로 저장. 오른쪽 파일 디렉터리는 폴더별 지연 조회하며 새로고침은 펼쳐진 하위 폴더도 갱신한다.
- 화면 이동 중 저장소별 편집 초안 유지. 파일 교체·다시 읽기·탭 닫기·프로젝트 닫기·네이티브 앱 종료에서 미저장 초안 보호.
- 파일 내용·inode·ctime·HEAD·브랜치 변경 시 오래된 원본에 대한 저장 거절. 원본 CRLF/BOM/실행 권한 보존. 저장은 staging/commit을 실행하지 않는다.
- 큰 상태 새로고침 버튼을 작은 아이콘으로 축소. 로컬 상태 확인과 Fetch는 역할이 다르므로 오프라인 확인 기능을 유지했다.
- 원격 관리의 주소·Upstream 설정은 필요하다. 사이드바 설정 진입점을 유지하고, 주 보기의 원격 탭과 설정 화면의 중복 Fetch/Pull/Push 버튼은 제거했다. 상단 GitToolbar와 브랜치 메뉴의 기존 원격 작업을 사용한다.

## 범위와 조건

- 현재 편집 범위는 1 MiB 이하 UTF-8 일반 파일 한 개. 폴더당 최대 5,000개 자식, 필요할 때만 하위 폴더 조회. 혼합 줄바꿈은 읽기 전용이며 링크·중첩 저장소·submodule·미해결 충돌은 해당 전용 경로 또는 외부 편집기를 사용한다.
- LSP·자동완성·파일 생성/이동/삭제는 이번 구현 범위에 포함하지 않았다.
- 앱 내부 Git 쓰기는 공통 저장소 큐를 공유한다. 외부 프로세스와 OS 수준의 배타 잠금은 제공하지 않으며, 원자 교체 직전에 원본을 다시 검사한다.
- 테스트는 임시 저장소·테스트 프로필·통제된 remote/Agent를 사용했다. 실제 사용자 저장소·로그인 세션 변경, 유료 Agent 호출, 패키징·서명·release는 수행하지 않았다.
- 실행 중인 사용자 앱은 재시작하지 않았다. main/preload 변경 반영에는 앱 재시작이 필요하다. 기존 500 kB 번들 경고는 남아 있다.
