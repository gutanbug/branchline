# 브랜치 이름 줄바꿈 검증

- 긴 브랜치 이름은 전체 줄바꿈하며 해당 행 높이를 자연스럽게 늘린다. HEAD는 넓은 그래프에서 윗줄에 두며 +N 툴팁은 유지한다.
- 실제 행 높이로 그래프의 선·노드·누적 지도를 맞추고, 읽던 커밋 SHA와 행 내부 위치를 기준으로 스크롤을 복원한다. 파일 탭 전환·창 크기 변경에서도 복원된다.
- 공통 ResizeHandle은 마우스를 놓는 최종 좌표까지 반영한다.
- 최소 창에서는 늘어난 행을 내부 스크롤로 탐색한다. 고정 세 행 노출 검사는 실제 가변 행의 도달성 검사로 변경했다.
