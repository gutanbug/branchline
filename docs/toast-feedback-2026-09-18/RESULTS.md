# 작업 결과 토스트 검증 · 2026-09-18

## 적용

- 공통 `ToastProvider`/`ToastMessage`를 먼저 추가하고 설치된 Base UI의 타이머·큐·포커스 관리를 재사용했다. 별도 의존성은 추가하지 않았다.
- Git 작업, Fetch/Pull/Push/Stash, 파일 저장·복사, 계정 연결, PR/MR·CI 실행, 작성자 프로필, MCP 설정 복사와 외부 링크 실패의 작업 결과를 고정 토스트로 표시한다.
- 성공·안내는 6초 후 닫는다. 경고·오류는 수동으로 닫거나 원래 상태가 해소될 때 제거한다. 진행 중 알림은 작업의 취소 동작을 유지한다.
- 필드 검증, 조회 로딩·오류, 충돌 복구에 필요한 지속 상태는 해당 화면에 유지한다. 같은 API 실패를 모달과 토스트에 중복 표시하지 않는다.

## 검증 범위

- Storybook: 5가지 상태, 같은 메시지 중복 제거, F6 진입, 닫기, hover 타이머 정지, 모달 포털·초안 유지, Esc가 모달을 닫지 않는지, 진행 알림의 Esc 보호, 취소 후 알림 교체.
- Electron 시나리오: 임시 Git 저장소의 실제 작업 결과, Fetch 이후 그래프 위치 유지, 모달 안의 오류, 상태 재조회 동작, 좁은 화면·접근성, 기존 Git·호스팅·복구 흐름. 호스팅 API와 Agent는 통제된 응답이며 실제 계정에 쓰기나 AI 호출을 하지 않는다.
- 760×580 상태별 스크린샷: `success-760.png`, `warning-760.png`, `error-760.png`. 긴 파일 경로도 토스트 안에서 줄바꿈하며 창 경계를 벗어나지 않는다.
- Premium strict 감사 및 DESIGN.md lint: 오류·경고 0개.

## 실행 결과

- 전체 `pnpm check` 통과: UI 193개, 백엔드 62개, 네이티브 브라우저·Electron 전체 시나리오·복구 시나리오·Storybook 빌드.
- Fetch 완료 토스트가 그래프의 위쪽 위치를 바꾸지 않는 회귀 검증을 추가했다.
- 기존 번들 크기 경고는 유지된다. 게시·커밋·Push는 수행하지 않았다.
- 최신 빌드로 데스크톱 앱을 실행하고 기존 프로젝트 탭과 커밋 그래프가 열리는 것을 확인했다.
