# 내 변경 사항 표시 개선 · 2026-09-15

## 반영

- 미추적 새 파일도 Git no-index patch를 CodeDiff로 표시한다. 스테이징 전후 동일한 초록색 추가 행, 통합/좌우 비교, 줄 번호와 마지막 줄 개행 유무를 제공한다.
- FileChangeRow/DiffStats 공통 컴포넌트로 작업 파일과 스테이징 파일에 `+추가 / −삭제` 줄 수를 표시한다. 작업 파일은 index 대비, 스테이징은 HEAD 대비다. 파일별 추가/수정/삭제 상태도 텍스트로 표시한다.
- 바이너리·대용량·조회 실패는 0줄로 표시하지 않는다. 빈 파일과 Git이 보고한 변경 없는 항목은 +0/−0이다.
- 44px 스테이징 버튼의 세로 늘어남을 제거하고 행 간격, 파일 선택 영역과 버튼 사이 12px 간격, 제목/파일 개수, 목록/스테이징/커밋 폼의 여백을 정리했다.
- 활성 내 변경 사항 화면에서만 통계를 조회한다. 상태 토큰 검증과 늦은 응답 폐기, 오류 재조회, 미추적 파일 통계의 최대 4개 동시 Git 실행을 적용했다.
