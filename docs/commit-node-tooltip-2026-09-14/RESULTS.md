# 커밋 점 브랜치 툴팁

- 커밋 점의 24px 호버 영역에 공통 Tooltip을 연결했다. 이름이 긴 LOCAL/REMOTE 브랜치와 직접 가리키는 TIP을 표시한다.
- 불러온 실제 부모 연결을 통해 포함 관계를 확인한다. 커밋에 라벨이 없어도 도달 가능한 refs를 보여주며, 필터로 빠진 부모를 건너뛰지 않는다. 레인 색·커밋 메시지로 브랜치를 추정하지 않는다.
- 최초 작업 브랜치나 저장소 전체의 완전한 포함 목록은 아니다. 확인된 이름이 없으면 확인 불가 안내를 표시한다.
- 키보드 행 포커스에서도 확인할 수 있다. +N이 있는 행은 기존 라벨 툴팁을 사용한다. 보이는 툴팁의 Esc는 툴팁만 닫고 선택을 유지하며, 화면 밖 툴팁은 Esc를 가로채지 않는다.
- 호버는 Git 명령·checkout·선택 변경을 실행하지 않는다. 점을 클릭하는 기존 커밋 선택은 유지한다.

## 검증

최종 `pnpm check` 종료 코드 0: lint, renderer build, UI 131개/39파일, native, Node 36개, 전체 Electron E2E, 초안 복원, Storybook build 통과. premium 정적 검사와 DESIGN lint 오류/경고 0. 기존 Vite 청크 경고는 유지한다.

실제 임시 저장소에서 라벨 없는 main 커밋, 공유 조상의 LOCAL/REMOTE refs, 호버·포커스·Esc 후 선택과 checkout 보존, 접근성을 확인했다. 그래프 가로 이동·가변 높이·Stash·파일 탭 회귀 검사도 통과했다. 사용자 저장소나 실제 계정에 테스트 쓰기를 하지 않았다.
