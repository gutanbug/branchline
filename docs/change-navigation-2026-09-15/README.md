# 변경 파일 탐색·부분 스테이징 1차 개선

2026-09-15. 전체 제품 리뷰의 우선순위 1을 적용했다. 나머지 리뷰 항목의 완료나 공개 배포를 의미하지 않는다.

- 작업 파일/스테이징: 파일명·경로 검색, 목록/트리 전환, 결과 수·빈 상태, 목록 높이 드래그/키보드 조절.
- 파일명과 디렉터리를 분리하고 긴 경로 때문에 행이 과도하게 늘어나지 않도록 정리. 전체 경로는 접근성 이름과 title로 제공.
- 일반 텍스트 수정: 실제 Git 변경 구간별 스테이징/해제. 작업 파일은 보존하고 index만 변경한다. 검토 후 저장소 상태/diff 변경, 잘못된 구간, 특수 변경은 거부한다. 처리 후 남은 파일 선택과 파일 행 포커스를 유지한다.
- 공통 UI: ChangeFileList → FilePathList로 커밋 파일 목록의 폴더 구현을 공유. ResizeHandle, CodeDiff, FileChangeRow와 기존 입력·버튼·Disclosure를 확장/재사용. 새 의존성 없음.

## 검증

실제 사용자 저장소 대신 임시 Git 저장소와 별도 Electron 프로필을 사용했다. Git 테스트는 두 구간 중 선택 적용, 구간 해제, 기존 staged/unstaged 분리, CRLF, 줄 수 변경, EOF 개행 없음, 한글·공백·대괄호 경로, 오래된 검토 거부, 새 파일/바이너리/모드 변경 거부를 확인한다.

Electron 검증은 검색·Tree·높이 키보드 조절·부분 적용/해제·index와 작업 파일 내용·기존 우클릭/확대/최소 창 크기·접근성을 확인한다. Storybook은 새 공통 컴포넌트의 빈 상태, 검색 결과, 폴더 접기, 키보드 높이 제한과 양쪽 diff의 구간 액션을 확인한다.

- 최종 `pnpm check` 종료 코드 0: lint·renderer 빌드, UI 158개/47개 파일, Git/보안 49개, native·Electron 전체/복구 검사, Storybook 빌드 통과. 근거: `check.log`. 기존 번들 크기 경고는 남아 있다.
- 초기 집중 검사 기록 `electron-check.log`에는 하위 메뉴 hover 타이밍 실패가 남아 있다. 최종 검사는 메뉴 클릭·키보드 경로와 전체 흐름을 통과했다. 그래프 테스트의 닫히는 툴팁 중복 조회도 열린 상태만 검사하도록 보완했다. 화면은 첫 UI 검증 캡처이며 최종 성공 근거는 `check.log`다.
- 디자인 정적 검사: `design-audit.json` (strict), `design-lint.log`.
- 화면: `partial-staging.png`, `working-changes.png`, `working-changes-narrow.png`.

## 제한과 다음 순서

행 단위 선택, 신규/삭제/이름 변경/바이너리/모드 변경 patch의 부분 적용은 지원하지 않는다. 검색은 현재 작업/스테이징 목록의 경로 필터이며 전체 스테이징 버튼은 검색과 무관하게 전체 파일에 적용한다. 검색·보기·높이는 화면 세션 상태이며 앱 재시작 후 저장하지 않는다.

다음 개선은 PR/MR 작업 필터와 안전한 Markdown 본문 표시다. 대형 그래프·Agent 진단·배포 검증 등은 기존 제품 리뷰의 미완료 항목으로 유지한다.
